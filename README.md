# Auto Avaliar QA — Cypress

Cypress automation repository for Auto Avaliar / Manhattan quality engineering.

## Scope
- Web/UI regression
- Responsive testing
- SEO UI validation
- Accessibility checks
- Component and integration scenarios
- Regression suites
- Test evidence and reports
- CI/CD execution

- `reports`
- `prompts`
- `scripts`
- `.github/workflows`

## Security
Never commit credentials, tokens, cookies, internal secrets or `.env` files. Use `.env.example` for variable names only.
